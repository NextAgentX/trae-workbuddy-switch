## FAQ

**May I fork it?**

Yes. Forking and modifying are both permitted; distribution, however, is still governed by this license (noncommercial only), and the `LICENSE` and copyright notices must be kept.

**Does internal use at a company count as commercial?**

Yes. An internal commercial project counts as "use in a for-profit business activity" and requires prior authorization.

**Is this "open source"?**

The accurate term is **source-available**: the source is visible, modifiable and noncommercially distributable, but **commercial use is restricted**, so it does not meet the OSI definition of open source. The README and the repository description therefore call it "source-available / noncommercial".

**I was using the MIT version — am I affected?**
